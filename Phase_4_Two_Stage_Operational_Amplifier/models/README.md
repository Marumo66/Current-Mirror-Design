# Model file

Place a separately obtained copy of `cmos130.lib` in this folder. The LTspice schematics in `schematics/` refer to it with `../models/cmos130.lib`.

The model used for the recorded runs is a generic 130-nm BSIM3 model, not a foundry-qualified PDK. I have not included it because I have not confirmed that it can be redistributed. Please obtain it from its original source.
