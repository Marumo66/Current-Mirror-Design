# Phase 4 schematic files

I keep the DC, AC and transient setups as three separate LTspice files. They use the same two-stage amplifier core and the same compensation values:

- CC = 1 pF
- RZ = 10.5 kΩ
- CL = 1 pF

The input and test-source connections differ between the files, so I keep the three configurations separate rather than switching analysis commands in one schematic.
